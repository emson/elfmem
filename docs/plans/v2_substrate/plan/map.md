Naming/layout rules not captured by a linter:
- Every new public `MemorySystem` method **must** have a corresponding `AgentGuide` entry
  in `src/elfmem/guide.py`'s `GUIDES` dict before merge (project rule, not enforced by CI).
- New significant modules get one line in `KEY_MODULES` in `src/elfmem/project.py`
  (surfaced by `elfmem doctor --modules`).
- `CHANGELOG.md` `[Unreleased]` section gets an entry for any user-facing behaviour change
  (CLI, config schema, MCP tools, docs). Format: Keep a Changelog, one bullet per logical
  change, lead with the affected symbol/command.
