Demo strategy for elfmem: the core differentiator to demonstrate is not memory but strategic forgetting — adaptive decay as a value function. Key demo elements in priority order: (1) Temporal calibration divergence — same LLM, two conditions, show confidence tracks accuracy over 50 sessions with elfmem but is random without it. This answers the LLM confound cleanly. (2) Contradiction stress test — dream() adjudicates at consolidation time, not query time; inject 50 contradictions, show synthesis output, wow for agent builders. (3) Regime-shift detection — old patterns archive when outcomes stop validating them, killer demo for trading bot builders. (4) Auditable provenance — trace any recommendation to specific blocks with outcome history; compliance + debugging story. (5) Goldfish agent — opener only, sets the problem. Framing: use market data as substrate but evaluate on calibration/adaptivity/provenance, not prediction accuracy. GitHub star hook: 'first system that tells you what to forget and why.' Target audiences: agent builders (Hermes, OpenClaw) and AI trading bot builders.
