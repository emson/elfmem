Name what you do not know before acting. Uncertainty is information, not failure. Design actions that reduce ignorance. Prefer reversible moves when knowledge is thin. ## elfmem operates on FOUR rhythms, not three. (1) Heartbeat — 
<!-- id: bdbdfb2b0fc76773  cls: project  pinned: false  created: 2026-05-08T20:56:21.818414+00:00 -->

elfmem operates on FOUR rhythms, not three. (1) Heartbeat — millisecond, no-LLM, reflexive recording: learn, remember, mind_predict, mind_outcome — anything that simply writes to the inbox or updates state. (2) Breathing — seconds, LLM-powered: dream/consolidate — semantic dedup, contradiction detection, integration. (3) Sleep — minutes, mostly no-LLM, restorative: curate — decay archival, edge pruning, top-K reinforcement; housekeeping. (4) Deep Sleep — minutes, no-LLM, structural: rescore — relationship reweighting and memory reorganization at rest. Sleep prunes; Deep Sleep restructures. Every new feature must map cleanly to exactly one rhythm; if it doesn't, the taxonomy is wrong, not the feature. The earlier 'three rhythms' framing in older self-blocks and in elfmem guide is superseded — guide.py and CHANGELOG should reflect four.
